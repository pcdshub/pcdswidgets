# screens directory

This directory should only contain screens that can be launched using the "pydm" launcher.

You might choose to include full pydm screens in pcdswidgets so they can be easily opened
from the widgets defined here without external dependencies.

If you're looking to build a designer widget, please put it into the "ui" directory.

All screens included here will be available to launch from the `pcdswidgets-show` entrypoint.

This directory can be loosely organized based on system, etc. but does not have any rigid rules.
